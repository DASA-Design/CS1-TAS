## v1.0.0 (2026-08-17)

Initial public release of the CS-1 TAS DASA evaluation.

- Model-only (Phase 1) Dimensional Analysis for Software Architecture (DASA)
  evaluation of the Tele Assistance System (TAS).
- Three independent predictive pipelines (analytic closed-form, stochastic SimPy
  DES, dimensional Pi-groups) plus a constructive coefficient-guided search, all on
  the loss-network FAIL-sink queueing model at the locked envelope
  (lambda_z = 323 req/s, K = 16, c = 1).
- Performance-versus-availability trade-off across four adaptations. Only the
  aggregate (S1 Retry and S2 Select-Reliable) passes both R1 (failure rate <= 1.0 %)
  and R2 (response time <= 26 ms); the search winner improves on it (0.03 % failure
  at 19.85 ms), cross-validated by an independent scipy optimiser.
- Documentation in `docs/`: `case-study.md` (what TAS is), `procedure.md` (how the
  experiment runs), `report.md` (the DASA modelling derivation, verdicts, and
  analysis).
- Reproducible inputs and verdicts under `data/config` and `data/results`. Figures
  are regenerated by running notebooks `01-analytic` through `06-comparison`.
- Requires PyDASA v0.7.1 (installed from source, see the README).
